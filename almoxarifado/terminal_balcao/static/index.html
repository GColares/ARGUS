Recebimento & Entrada de Materiais

Registre compras, entregas de fornecedores ou notas fiscais utilizando o botão superior. O sistema converte automaticamente a embalagem comercial para a menor unidade física de estoque (metros, litros, unidades) e gera a etiqueta com endereçamento WMS 3D.

Diretrizes de Recebimento no Polo:

  • Dupla Unidade Automática: Entradas de bobinas/rolos (ex: 100m) e latas (ex: 18L) são convertidas para a unidade base para permitir saídas fracionadas.
  • Endereçamento WMS 3D: Toda entrada atualiza a localização física (Ambiente > Estrutura > Posição).
  • Etiqueta Imediata: Após salvar, imprima a etiqueta gerada para afixação na prateleira ou na embalagem.
